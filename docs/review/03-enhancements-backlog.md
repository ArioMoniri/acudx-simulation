## 1. How to read the table

- **Rank** orders by (learner value + educator value) weighted against effort and risk. Ties go to the item that unblocks another row.
- **Learner value / Educator value**: H, M, L.
- **Effort**: S (under one day, one or two files, unit tests only), M (two to five days, touches more than one layer), L (a sprint or more, new service or data model).
- **Risk**: L (isolated, reversible), M (touches shared state or a shipped flow), H (clinical correctness or identity surface).
- **Dependency**: what must exist first, or "none".
- **Evidence**: the research, review or architecture section that motivates the item. Competitor claims cite the vendor page quoted in research 13.

Items 1 to 3 are implemented in this pass (section 3). Everything else is proposed.

## 3. Implemented in this pass

Chosen for S effort and L risk, with no overlap on files other agents are editing heavily (`server/providers/gpu_worker.py`, `infra/`, `encounterStore.ts`, the Interview tab).

1. **Item 1, stable `learner_id`.** `web/src/state/profileStore.ts` gains `selectLearnerId` (verified `sub` when the profile is verified, otherwise `local:` plus a stable hash of `localId`); `web/src/lib/caseGenV2.ts` fills `learner_id` on `generateCaseV2`, `streamCaseGenV2` and `directorStep` when the caller did not set it. Server routes already consume the field (`server/orchestration/routes.py`, `graph.py`). Tests: `caseGenV2.test.ts`, `profileStore.test.ts`, `server/tests/test_orchestration_routes.py` (memory written on a director error and read back from `/v2/learner/{id}`).
2. **Item 2, periodic probe job.** `server/registry/jobs.py` adds `ProbeScheduler` (interval from `PROBE_INTERVAL_MINUTES`, default 10, 0 disables); started in the app lifespan next to the GPU reaper. Tests: `server/tests/test_registry_jobs.py`.
3. **Item 3, telemetry retention purge.** `TelemetryRecorder.purge_older_than(days)` and `RetentionPurger` in the same jobs module, honouring `telemetry.retention_days` from the settings table (unset or 0 keeps everything). Tests: `server/tests/test_registry_jobs.py`, `server/tests/test_telemetry.py`.
